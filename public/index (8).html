// FAQ
What does AntiSec actually do?
AntiSec fetches the raw HTML source of any public website via a serverless engine and analyses it — extracting all links, scripts, stylesheets, images, meta tags, email addresses, phone numbers, and more. Think of it as a recon snapshot of a target page. Because fetching happens on the server, there are no CORS limitations.
Why does it fail on some websites?
Some sites actively block automated requests, require a login, use heavy JavaScript rendering (SPAs), or return CAPTCHA challenges. AntiSec works on static, publicly accessible HTML pages. Pages that only load via JavaScript or behind auth walls cannot be scraped this way.
Is this legal to use?
AntiSec only reads publicly accessible HTML — the same data any browser fetches. Never use this tool against targets you don't have permission to analyse. You are responsible for how you use it.
Why does it say "all proxies failed"?
Fetching is done server-side so CORS proxies are no longer needed. If a scan fails it usually means: the target is down, behind a Cloudflare/WAF block, requires JavaScript rendering, or needs authentication. Try a simpler, static HTML page.
Can I download the results?
Yes — use the action buttons below the results to copy or export data. The full source viewer lets you select and copy any section of the raw HTML.
Is my data stored anywhere?
No. Everything runs in your browser. No URLs, results, or source code are sent to any AntiSec server.
// How To Use
01
Enter a target URL
Paste any public URL into the input field — with or without https://. Example: example.com or https://example.com/page. The tool auto-adds the protocol if missing.
02
Hit Execute
Click the Execute button or press Enter. The tool will route through multiple CORS proxies to fetch the raw HTML source of the target page.
03
Wait for results
Watch the progress log in real time. If the first proxy fails, the tool automatically tries the next one. The scan usually completes in 3–10 seconds.
04
Browse the tabs
Results are split into tabs: Overview (meta + stats), Links (all hrefs), Assets (scripts, CSS, images), Intel (emails, phones, comments), and Source (raw HTML).
05
Export your data
Use the action buttons below the results — Copy Links, Copy Assets, Copy Intel, or Copy Source — to export results to your clipboard. From the Source tab you can also toggle line wrap.
06
Start a new scan
Click New Scan at the top of the results to reset and scan another target. The previous results are cleared from memory.
